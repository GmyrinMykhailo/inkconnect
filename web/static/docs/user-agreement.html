Пользовательское соглашение и согласие на обработку персональных данных

Это тестовый документ-заглушка для проверки отображения соглашения в модальном окне во время регистрации.

1. Общие положения

Пользователь подтверждает, что предоставляет данные добровольно и использует сервис в тестовом режиме разработки.

2. Какие данные могут обрабатываться

Для создания аккаунта могут использоваться никнейм, email, номер телефона, ФИО, город и иные данные, введённые в форму регистрации.

3. Цель обработки данных

Данные используются для создания учётной записи, авторизации, отображения профиля и тестирования бизнес-логики проекта InkConnect.

4. Согласие пользователя

Отмечая чекбокс в форме регистрации, пользователь подтверждает согласие с этим тестовым документом и с обработкой введённых персональных данных.
